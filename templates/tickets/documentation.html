Übersicht

Das Enhanced Ticket System bietet flexible Lösungen für Ihr Ticket-Management.

Hauptfunktionen: Kategorien, Prioritäten, Status-Workflows, Custom Fields, Vorlagen, SLA-Regeln

Kategorien

Organisieren Sie Tickets nach Themengebieten.

Einstellungen:

  • Name: Eindeutiger Kategoriename
  • Beschreibung: Optionale Beschreibung
  • Farbe: Hex-Farbcode (#RRGGBB)
  • Icon: Bootstrap Icon (z.B. 'bug', 'gear')
  • SLA: Standard-Bearbeitungszeit in Stunden

Prioritäten

Definieren Sie die Dringlichkeit von Tickets.

Best Practices:

  • Verwenden Sie 3-5 Prioritätsstufen
  • Setzen Sie realistische Zeiten
  • Level 1-5 (5 = höchste Priorität)

Status & Workflows

Steuern Sie den Lebenszyklus Ihrer Tickets.

Standard-Status:

  • new: Neu erstellt
  • open: In Bearbeitung
  • pending: Wartet auf Rückmeldung
  • resolved: Gelöst
  • closed: Geschlossen

Custom Fields

Erstellen Sie benutzerdefinierte Felder.

Verfügbare Feldtypen:

  • text: Einzeiliger Text
  • number: Numerische Werte
  • date: Datumsauswahl
  • select: Dropdown-Auswahl
  • checkbox: Ja/Nein

Vorlagen

Beschleunigen Sie die Ticket-Erstellung.

Platzhalter:

  • {user} - Name des Erstellers
  • {date} - Aktuelles Datum
  • {time} - Aktuelle Uhrzeit

SLA-Regeln

Service Level Agreements definieren.

Regel-Priorität:

  1. Spezifische Kategorie + Priorität
  2. Nur Kategorie
  3. Nur Priorität
  4. Standard-SLA
