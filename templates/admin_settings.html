OAuth 2.0 Einstellungen
OAuth ermöglicht Benutzern die Anmeldung mit Google, Microsoft oder GitHub Konten. Die Konfiguration erfolgt über Umgebungsvariablen (Environment Variables).
Wenn aktiviert, werden neue Benutzer automatisch erstellt wenn sie sich per OAuth anmelden.

SAML SSO Einstellungen (Enterprise)
SAML SSO ermöglicht Enterprise Single Sign-On mit Ihrem Identity Provider (z.B. Azure AD, Okta, Auth0). Die vollständige Konfiguration erfolgt über Umgebungsvariablen.
Erforderliche SAML Environment Variables:
Service Provider (SP):
  • SAML_SP_ENTITY_ID
  • SAML_SP_CERT (optional)
  • SAML_SP_KEY (optional)
Identity Provider (IdP):
  • SAML_IDP_ENTITY_ID
  • SAML_IDP_SSO_URL
  • SAML_IDP_SLO_URL (optional)
  • SAML_IDP_CERT
Hinweis: Die SAML Callback URL für Ihren IdP lautet: {{ request.url_root }}saml/acs
